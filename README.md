# Dream Cosmetics · Pilotage commercial (prototype)

Prototype de tableau de bord pour la direction générale. **Toutes les données sont fictives** (démonstration).

- `index.html` : le tableau de bord ; `brancher.html` : structure des fichiers à remplacer par l'export réel.
- `data/` : les fichiers lus par la page (CSV séparés par des points-virgules, UTF-8).
- Contours administratifs : geoBoundaries (CC BY 4.0). Bibliothèques : Leaflet, Chart.js.
